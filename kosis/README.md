# KOSIS 초고속인터넷 회선 수

`npm run fetch-kosis-broadband` 가 KOSIS 통계표
[「초고속인터넷 기술방식별·사업자별 회선 수」](https://kosis.kr/statHtml/statHtml.do?orgId=127&tblId=DT_127006_A004&conn_path=I2)
(orgId=127, tblId=DT_127006_A004)를 원표 전 기간 내려받아 이 폴더에 저장한다.

- `broadband-lines.json` — 출처 메타 + 세로형 레코드
- `broadband-lines.csv` — 같은 레코드의 CSV

| 축 | 값 |
| --- | --- |
| 사업자 | 합계, KT, SK브로드밴드, SKT(재판매), LG U+, 종합유선, 기타 |
| 기술방식 | xDSL, LAN, HFC, FTTH |
| 단위 | 회선 |

원표에 `위성` 항목이 있으나 전 기간 수록값이 없어 조회 결과에 나타나지 않는다.

## 수록기간

원표가 **2017.12부터** 제공된다. 그 이전 시점은 KOSIS에 없다. KOSIS 통계표
검색 결과 기술방식별 × 사업자별 구분을 함께 가진 통계표는 이 표가 유일하고,
인접 후보인 `TX_374_2009_H1007`(정보통신서비스 가입자수)은 2007.01~2008.12이며
기술방식 구분이 없다.

## 원표 주석

- '20.12월부터 SK브로드밴드의 PC방 인터넷회선을 초고속인터넷회선 수치에서 제외
  ('17년 12월 ~ '20년 11월 수치 소급 적용)
- SK브로드밴드 '20년 5월 가입자의 경우 티브로드가 흡수합병되면서 기존 종합유선에
  포함되어 있던 수치가 합산됨

## 검증

저장 전에 모든 시점·기술방식에 대해 KOSIS가 주는 `합계` 와 개별 사업자 합이
같은지 확인한다. 어긋나면 파일을 쓰지 않고 실패한다.
